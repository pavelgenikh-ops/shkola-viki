# 🎒 Школа Вики

Обучающая игра по программе **2 класса** («Школа России»). Сделана для дочери, работает в браузере,
ничего устанавливать не нужно.

**Открыть: https://pavelgenikh-ops.github.io/shkola-viki/**

## Что внутри

**101 урок в шести предметах, 303 уровня.** Задания генерируются заново каждый раз — одинаковых уроков не бывает.

| Предмет | Уроков | О чём |
|---|---|---|
| 🔢 Математика | 16 | числа до 100, столбик, задачи, уравнения, часы, деньги, умножение, периметр |
| 📝 Русский язык | 20 | предложение, текст, состав слова, все орфограммы 2 класса, части речи |
| 📚 Чтение | 17 | фольклор, Пушкин и Крылов, писатели детям, стихи, большие рассказы, рассуждение |
| 🌍 Окружающий мир | 18 | природа, животные, экономика, безопасность, ориентирование, карта мира |
| 🔠 Английский | 13 | алфавит, 236 слов Spotlight 2, фразы, аудирование |
| 🧩 Логика и смекалка | 17 | ряды, судоку, шифры, лабиринты, симметрия, задачи с подвохом, мемори |

В каждом уроке три уровня: лёгкий (проще программы), средний (по учебнику) и сложный (на вырост).

Ещё есть **6 мини-игр** на время, **10 дипломов** с печатью на принтер, наклейки, звания, задание дня
и панель для родителей со статистикой.

## Как устроено

Чистый HTML, CSS и JavaScript без сборки и зависимостей. Прогресс хранится в браузере (localStorage).

```
index.html         оболочка
js/engine/         реестр предметов, 9 типов заданий, опыт и награды
js/data/*.js       контент: каждый предмет — один файл с генераторами заданий
js/ui/             экраны, мини-игры, дипломы
js/lib/            утилиты, звук, озвучка, хранилище
_dev/              спецификация контента, валидатор, смоук-тест
```

Формат контента описан в `_dev/КОНТЕНТ-СПЕЦИФИКАЦИЯ.md`. После правки заданий:

```
_dev/node.exe _dev/check.js js/data/math.js     # схема и разнообразие
fetch('_dev/smoke.js').then(r=>r.text()).then(eval)   # живой прогон в консоли браузера
```

## Голос

Задания и объяснения читаются вслух, есть десять характеров голоса. На компьютере первые три считает
нейросеть **Piper** прямо на месте, без интернета: файлы модели (146 МБ) лежат в папке `voice/`,
в репозиторий не входят и скачиваются скриптом `_служебное/скачать голос.bat`.
На телефоне и без этой папки приложение говорит системным голосом.

## Локальный запуск

`Запустить.bat` — поднимает локальный сервер и открывает приложение в Edge.
Сервер нужен только нейросетевому голосу; без него достаточно открыть `index.html`.

Подробности — в `ПРОЧТИ.md`.
