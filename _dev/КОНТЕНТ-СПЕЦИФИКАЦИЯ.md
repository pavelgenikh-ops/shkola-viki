# Спецификация файла контента предмета

Приложение «Школа Вики» — обучающая игра для девочки 8 лет (2 класс). Каждый предмет — один файл `js/data/<subject>.js`.
Файл подключается обычным `<script>` (НЕ модуль, НЕ fetch — приложение открывается с диска по `file://`).
Всё содержимое — в одном IIFE. Никаких обращений к `document`, `window.location`, сети, картинкам-файлам. Только эмодзи и текст.

## Каркас файла

```js
(function () {
  const S = window.SCHOOL;
  const U = S.util;   // утилиты (см. ниже)
  const V = S.vis;    // визуальные помощники (см. ниже)

  // --- банки данных предмета (массивы слов, фактов, задач) ---

  // --- генераторы ---

  S.registerSubject({
    id: 'russian',                 // латиницей, уникально
    title: 'Русский язык',
    emoji: '📝',
    color: '#ff6b8a',              // основной цвет предмета
    desc: 'Буквы, слова и правила', // 2–5 слов
    sections: [
      { title: 'Звуки и буквы', lessons: [
        {
          id: 'ru-zhi-shi',          // латиницей, уникально во всём приложении, с префиксом предмета
          title: 'Жи-ши, ча-ща, чу-щу',
          emoji: '🐍',
          rule: 'В сочетаниях <b>ЖИ</b> и <b>ШИ</b> всегда пишем <b>И</b>: ж<b>и</b>раф, маш<b>и</b>на. ' +
                '<b>ЧА-ЩА</b> — с буквой <b>А</b>, <b>ЧУ-ЩУ</b> — с буквой <b>У</b>.',
          gen(level) { /* level = 1 | 2 | 3 → вернуть объект задания */ }
        }
      ]}
    ]
  });
})();
```

Поле `rule` — короткая карточка правила (1–4 предложения, HTML: только `<b>`, `<i>`, `<br>`), показывается перед уроком.
У каждого урока `rule` обязателен (для окружающего мира и чтения — короткая справка по теме).

## Уровни

`gen(level)` вызывается много раз подряд (8–12 раз на урок), каждый раз должен возвращать **новое случайное** задание.
Движок отбрасывает точные повторы, поэтому банк должен давать **не меньше 15 разных заданий на каждый уровень**.

| Уровень | Смысл | Как выглядит |
|---|---|---|
| 1 | Вводный, легче программы | 2–3 варианта ответа, маленькие числа, короткие слова, подсказка прямо в формулировке или в `hint` |
| 2 | Уровень программы 2 класса | 3–4 варианта, обычные задания из учебника |
| 3 | Усложнённый (конец 2 класса / начало 3-го) | 4–6 вариантов, ловушки, два действия, несколько пропусков, длинные слова, ввод с клавиатуры вместо выбора |

Уровень должен ощутимо отличаться — не только числами, но и типом задания (на уровне 1 — `choice`, на 3 — `input`, `gap` с несколькими пропусками, `order`).

## Общие поля задания

| Поле | Обяз. | Что это |
|---|---|---|
| `type` | да | один из типов ниже |
| `prompt` | да | формулировка для ребёнка: коротко, на «ты», можно эмодзи, HTML только `<b>`, `<i>`, `<br>` |
| `visual` | нет | HTML над формулировкой: результат `V.*` или просто строка эмодзи `'🍎🍎🍎'` |
| `hint` | нет | подсказка, показывается после первой ошибки (у уровня 1 — желательно всегда) |
| `explain` | нет | объяснение после ответа: правило одной фразой + верный ответ. **Нужен у большинства заданий** |
| `say` | нет | текст для озвучивания кнопкой 🔊 (диктанты, английские слова) |
| `sayLang` | нет | `'ru-RU'` (по умолчанию) или `'en-US'` |
| `autoSay` | нет | `true` — озвучить автоматически при показе (для «послушай и выбери») |

## Типы заданий

### `choice` — выбор одного (или нескольких) вариантов
```js
{ type: 'choice', prompt: 'Какое слово написано верно?', options: ['жираф', 'жыраф'], answer: 'жираф',
  explain: 'ЖИ пишем с И.' }
// несколько правильных:
{ type: 'choice', multi: true, prompt: 'Выбери все имена существительные', options: ['кот', 'бежит', 'стол', 'синий'],
  answer: ['кот', 'стол'] }
// крупные плитки (эмодзи, короткие слова):
{ type: 'choice', big: true, prompt: 'Где кот?', options: ['🐱', '🐶', '🐭'], answer: '🐱' }
```
`options` — 2–6 уникальных строк; `answer` обязан совпадать с одним из вариантов (при `multi` — массив).
Варианты перемешивай сам (`U.opts`, `U.shuffle`) — движок порядок не меняет.

### `input` — ввод с клавиатуры
```js
{ type: 'input', prompt: 'Сколько будет 36 + 7?', answer: 43, mode: 'num' }
{ type: 'input', prompt: 'Напиши проверочное слово к слову «трава»', answer: ['травы', 'травка'], mode: 'text' }
```
`mode: 'num'` — числовой ответ; `'text'` — текст (сравнение без учёта регистра, ё = е). `answer` — значение или массив допустимых.

### `match` — соедини пары
```js
{ type: 'match', prompt: 'Соедини слово и перевод', pairs: [['cat', 'кот'], ['dog', 'собака'], ['fish', 'рыба']] }
```
2–6 пар, левые и правые части уникальны. Движок сам перемешает правый столбец.

### `order` — расставь по порядку
```js
{ type: 'order', prompt: 'Собери предложение', items: ['Мама', 'мыла', 'раму.'] }
{ type: 'order', prompt: 'Расставь числа от меньшего к большему', items: ['17', '23', '41', '58'] }
```
`items` — в **правильном** порядке (движок перемешает). 3–8 уникальных элементов.

### `sort` — разложи по группам
```js
{ type: 'sort', prompt: 'Разложи: живая и неживая природа',
  groups: [ { name: 'Живая 🌱', items: ['берёза', 'ёж', 'гриб'] }, { name: 'Неживая 🪨', items: ['камень', 'вода', 'облако'] } ] }
```
2–4 группы, всего 4–10 элементов, каждый элемент только в одной группе.

### `gap` — вставь пропущенное
```js
{ type: 'gap', prompt: 'Вставь букву', text: 'ж_раф', answers: ['и'], options: ['и', 'ы'] }
{ type: 'gap', prompt: 'Вставь буквы', text: 'ч_йка ж_вёт у моря', answers: ['а', 'и'], options: ['а', 'я', 'и', 'ы'] }
```
Пропуск — символ `_` (1–4 пропуска). `answers` — по одному на каждый пропуск по порядку. `options` — общий набор плиток
(2–6), обязательно содержит все ответы. В пропуск можно ставить букву, слог или короткое слово.

### `spell` — собери слово из плиток
```js
{ type: 'spell', prompt: 'Собери слово: 🍎', word: 'apple', say: 'apple', sayLang: 'en-US' }
{ type: 'spell', prompt: 'Собери слово из слогов', word: 'молоко', parts: ['мо', 'ло', 'ко'] }
{ type: 'spell', prompt: 'Собери слово: 🐘', word: 'elephant', extra: ['k', 'o'] }   // extra — лишние плитки-ловушки
```
`parts` (если есть) при склейке должны дать `word`.

### `compare` — сравни (< > =)
```js
{ type: 'compare', prompt: 'Поставь знак', a: '34 + 5', b: '40', answer: '<' }
```

### `memory` — найди пары (игра «Мемори»)
```js
{ type: 'memory', prompt: 'Найди пары: слово и перевод', pairs: [['cat', 'кот'], ['dog', 'собака'], ['cow', 'корова']] }
```
3–6 пар, все карточки уникальны. Используй как «разминку» на уровне 1 или бонус.

## Утилиты `U = S.util`

| Вызов | Результат |
|---|---|
| `U.rand(min, max)` | целое от min до max включительно |
| `U.chance(0.3)` | true с вероятностью 30 % |
| `U.pick(arr)` | случайный элемент |
| `U.pickN(arr, n)` | n разных случайных элементов |
| `U.pickOther(arr, exclude)` | случайный элемент, не равный exclude (или не из массива exclude) |
| `U.shuffle(arr)` | перемешанная копия |
| `U.uniq(arr)` | без дублей |
| `U.range(a, b)` | [a, …, b] |
| `U.cap(s)` | Первая буква заглавная |
| `U.plural(n, ['яблоко','яблока','яблок'])` | нужная форма слова |
| `U.count(n, forms)` | `'5 яблок'` |
| `U.distractNums(answer, n, min, max)` | n чисел-ловушек ≠ answer |
| `U.nearNums(answer, n, spread, min)` | ловушки рядом с ответом |
| `U.opts(answer, distractors)` | перемешанные уникальные варианты (строки) |
| `U.numOpts(answer, n, min, max)` | варианты: ответ + n числовых ловушек |

## Визуальные помощники `V = S.vis` (возвращают HTML для `visual`)

| Вызов | Что рисует |
|---|---|
| `V.emojis('🍎', 7)` | 7 яблок в ряд (перенос по 10) |
| `V.groups('🍬', 3, 4)` | 3 коробки по 4 конфеты (смысл умножения) |
| `V.column(45, 23, '+')` | пример в столбик с местом для ответа |
| `V.clock(8, 30)` | аналоговые часы |
| `V.grid([[1,'',3],[3,1,'?']])` | таблица-сетка (`''` — пусто, `'?'` — подсвечена) |
| `V.rect(6, 4)` / `V.square(5)` | прямоугольник/квадрат с подписями сторон (см) |
| `V.triangle(3, 4, 5)` | треугольник с подписями сторон |
| `V.polyline([3, 5, 2])` | ломаная с длинами звеньев |
| `V.text('<p>…</p>')` | абзац текста для чтения |
| `V.big('🦊')` | крупный эмодзи/надпись |
| `V.cards([['🍎','apple'],['🍌','banana']])` | карточки с подписями |

## Требования к качеству

1. **Правильность превыше всего.** Орфография, факты, арифметика — без ошибок. Каждый неверный вариант должен быть действительно неверным,
   каждый верный — единственно верным (в `choice` без `multi` не должно быть двух подходящих вариантов).
2. **Тон** — дружелюбный, на «ты», короткие фразы, эмодзи уместны, но не в каждом слове. Никаких «неправильно, подумай ещё» в `explain` —
   только объяснение и правило.
3. **`explain` почти у каждого задания**: одно-два предложения — правило + правильный ответ. Например: «Проверочное слово — тра́вы, значит пишем А: трава».
4. **Разнообразие типов** внутри урока: минимум 3 разных типа заданий на урок (на разных уровнях можно разные).
5. **Банки данных большие**: минимум 15 разных заданий на каждый уровень каждого урока (валидатор ругается, если меньше).
6. **Числа и слова — по возрасту**: математика в пределах 100, слова из словаря 2 класса, факты — из учебника.
7. Никаких длинных текстов в `prompt` (до ~200 символов). Тексты для чтения — в `visual` через `V.text(...)`.
8. Тексты авторов XX века (Барто, Михалков, Носов, Драгунский, Успенский…) **не цитировать** длиннее одной строки — только вопросы по сюжету,
   героям, названиям. Народные тексты, Пушкин, Крылов, Тютчев, Фет, Толстой — цитировать можно.

## Проверка

Из папки приложения:
```
_dev\node.exe _dev\check.js js\data\russian.js
```
Валидатор загружает файл, вызывает каждый `gen(level)` по 40 раз, проверяет схему и разнообразие. Должно быть **0 ошибок**;
предупреждения — просмотреть и по возможности убрать. Файл считается готовым только с чистым прогоном.
